Glycan edge case survey

Multi-omics · #glycosmos

Refining the definition of a glycan by examining the edge cases either side of the glycan / non-glycan divide. A continuation of the BH25 project.

  • Select optimal examples of the edge cases
  • Try AI as a way to assemble a set for human review
  • Discuss what glycoinformatics needs in order to handle in-scope and out-of-scope cases

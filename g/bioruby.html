BioRuby and Ruby for Bioinformatics

Technology · #ruby

BioRuby is an open-source bioinformatics library for Ruby. Parts of the codebase are twenty years old and want modernising, with AI coding agents doing some of the work.

  • Improve code, tests and documentation using AI coding agents
  • Adopt modern Ruby standards: rbs type annotations, simplecov, GitHub Actions
  • Discuss what shape a library should take to suit both AI and people
  • Look into recent Ruby bioinformatics tools such as togows-cli and dratools

Team: Naohisa Goto, Kozo Nishida

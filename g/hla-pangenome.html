Creating HLA pangenome graphs using Asian genomics data

Biomedical

Combining genomics data from Asian populations with pangenome tools such as pggb and minigraph-cactus to build HLA graphs, using the NIG supercomputer and publicly available data.

  • Gather the genomics data
  • Build pangenome graphs for each population
  • Benchmark and compare

Team: Hassan Sibroe Abdulla Daanaa, Dawn Chen, Kazumichi Fujiwara, Robert Hoehndorf, Shin-ichiro Tago, Yosuke Kawai, Apiwat Sangphukieo, Toshiaki Katayama
